# Aruna — A Little Movie of You

A cinematic personal website for Aruna, built with HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in your browser, or run a simple local server:

```bash
npx serve .
```

## Host on GitHub Pages

1. Create a new GitHub repository (e.g. `aruna`).
2. Push this folder to the repo.
3. On GitHub: **Settings → Pages → Build and deployment**.
4. Set **Source** to **Deploy from a branch**.
5. Choose branch `main` (or `master`) and folder `/ (root)`.
6. Save — your site will be live at:

`https://YOUR-USERNAME.github.io/REPO-NAME/`
